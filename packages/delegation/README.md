# Bounded delegated sessions

`DelegationCoordinator` persists explicit `DelegationTask` packets with objective, acceptance, provenance, artifact inputs, scope, canonical writable roots, model/effort profile, resource envelope, output location, cancellation and depth. Trusted grants reject audience broadening, unsupported profiles, larger envelopes, excess children/concurrency/depth and overlapping active ownership. Input/output artifacts require stored bytes and audience metadata from trusted `artifactScope`.

The injected `executeChild(task, signal)` must admit a distinct child through the same durable runtime with `parentRunId`, allocate its grant, run the selected `ShellPort`, and return `{ childRunId, artifacts, observations? }`. It is deliberately not a second imitation of the agent shell. The shared runtime ledger accounts physical requests and descendant cancellation; the coordinator also enforces child wall time and propagates cancellation. Trusted `currentDepth` prevents a child from resetting recursion depth. The runtime adapter must derive that depth from its persisted parentage and narrow grants to the child's actual packet.

Only `delegation.start` is model callable. After completion, a trusted parent calls `inspect(id)` to read and validate actual artifact bytes/digests. `judge(id, inspection, checks)` requires evidence for every predeclared criterion and retains a verdict artifact. A child's result prose cannot accept itself. Missing/lost outcomes remain uncertain across recovery, without automatic rerun. Rejected results release completed ownership and need a new task for repair. The host must call `recover()` on restart before scheduling additional tasks.

The integration test runs two actual child `ShellPort` sessions through `DurableRuntime`, creates files in separate namespace workspaces, runs real Node checks, collects artifact receipts and records one parent acceptance and one rejection after inspection. The intelligence is a deterministic fixture; live model competence and ordinary application wiring remain L02/L08/L09 gates.
