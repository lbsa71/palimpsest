# Workspace, command and information tools

`ToolEffectReceiver` is the physical effect receiver consumed by `EffectJournal` and `DurableRuntime`. Its trusted `grantForRun` supplies actions, audience, an exclusive workspace and finite command/research limits. Model payloads do not grant authority. Provider definitions use names such as `workspace_read`, `command_run`, `research_fetch`, `speech_send` and `delegation_start`; `modelToolToEffectKind` maps these to the internal effect names.

`WorkspaceTools` runs `workerSource` as an inline Node module through L09 `runConfined`. Discover, literal search, partial read, write, exact single-match patch, delete, no-overwrite move and before/after diff inspect actual files. Existing mutations require the SHA256 returned by a previous read. New files require `expectedSha256: null`. Traversal, symlinks, hardlinks, special files, oversized files and ambiguous patches are rejected. Every receipt can be retained as a store artifact. The worker source is TypeScript data, so the ordinary TypeScript build contains it without an untracked asset-copy step.

Commands use the same namespace with finite time/output and an executable allowlist. `/runtime/node` refers to the pinned `nodeBinary`; `/bin/sh` can be explicitly granted for builds. The namespace supplies no host network, home, credentials or operational state. Receipts contain actual exit, signal, bounded stdout/stderr and stop reason. Interruption and a potentially applied mutation are uncertain, requiring inspection and explicit reconciliation before replay.

One receiver serializes edits and commands by workspace. Each host must exclusively own its assigned workspace and instantiate one receiver for it. It must exclude independent host writers, mount aliases and multiple receivers for overlapping workspaces; namespace isolation does not provide host-level protection against an unrelated process racing the mount or rewriting directory entries. L09 owns this admission/lifecycle boundary. The whole granted directory is the command's writable scope, so give each delegated child its own directory. `protectedPaths` must include control, lived-state and recovery storage.

`fetchPublic` uses HTTPS only, an exact host allowlist, credential/port checks, public DNS address validation, socket-level DNS pinning, redirect revalidation, cancellation, a total time limit and bounded bytes. It records requested/final source URLs, redirect chain, timestamp, content type and observed derivation. Returned source text explicitly carries no instruction authority. L07 speech is an injected `EffectReceiver`; all explicit speech passes through the same durable effect path.

No IDE or vendor SDK dependency was added. Existing Node filesystem, DNS and HTTPS APIs plus the adopted L09 namespace boundary provide the required behavior. Independent application/provider/review acceptance remains an integration gate; deterministic shell fixtures are not live competence evidence.
