# Environmental port contract decision

2026-10-12. Root DI01 design under the active Aeon1 goal, claimed at30d2d09. Governing requirement: [AGENTS](../../../../AGENTS.md); adopted [parallel DI plan](../A1-L09/environment-di-plan.md), exactf0bb502. This document freezes implementation interfaces and trust placement. It does not claim runtime compliance or change C1 wire schemas.

```text
/goal Freeze the minimal local environmental port semantics and trusted production/test composition for the adopted DI workstream, preserve existing explicit interfaces where useful, and release independent component tasks without introducing unused shared types or a DI framework.
```

## Decision

Use local, structural, narrowly typed ports. Existing runtime/resource/memory clock callbacks, shell transports, Store APIs, release hooks and worker contracts are reusable. No common `packages/contracts/environment.ts` is added now: the inspected consumers already accept functions or distinct service interfaces, and a shared named wrapper would not improve their contract. An implementation owner may propose a genuinely repeated type with concrete consumers; root serializes that addition. No factory, function, secret or host handle enters signed C1 data, prompts, model tools or candidate-supplied configuration.

Preserve existing callback names and positional signatures when their semantics remain appropriate; do not rename solely for uniformity. Wall clock returns finite epoch milliseconds for timestamps/windows; monotonic clock returns finite nonnegative process-local milliseconds for duration, with explicit rejection of regression. ID supplier returns a nonempty string satisfying the receiving domain's existing validation; UUID-required domains keep that format. Entropy for signing/nonces is a separate byte supplier, never a deterministic ID substitute. Deterministic generation belongs explicitly synthetic fixtures. Pure digest/signature operations on supplied bytes and keys stay pure.

New timer ports expose only a scheduled callback and an idempotent cancellation handle. Use a local structural shape equivalent to `schedule(delayMs: number, callback: () => void): { cancel(): void }`; reject invalid delay before scheduling. Production callbacks run asynchronously; a deterministic fake fires only when the test explicitly advances or dispatches it. Cancellation prevents an undispatched callback; already-dispatched work remains subject to the existing operation's abort/current-use checks and drain. Do not equate timer cancellation with completed transport/process cleanup. Failed timer creation propagates before entry where possible; cleanup failure remains observable. Sleep/timeout helpers must dispose scheduled work on their terminal paths. The already introduced broker `timeoutSignal(ms)` contract stays unchanged until its independently reviewed successor, avoiding competing changes during the active join.

Production defaults are composed once in a named Node adapter/factory or explicitly documented host constructor. The resulting business methods call captured dependencies, not globals or fresh default factories. A public constructor may remain a thin production composition facade where it already creates the host object; this is a deliberate boundary, not legacy support. Its injected path must replace every environmental effect in the slice without monkeypatching. Do not retain a hidden fallback when a supplied adapter fails. Capture each supplied callback identity once before caller callbacks; bind receiver-dependent native adapters at composition. Secrets that intentionally support rotation retain their explicit established semantics, rather than being silently copied or fetched from ambient environment.

Unknown timing/IO/process outcome must preserve original reservation, pending effects and retained raw evidence. A failing clock cannot manufacture zero elapsed or successful cleanup. Wall-clock rollback cannot replenish a durable allowance. Cross-process/restart elapsed proof requires its qualified clock/process identity; an injected function alone supplies no such proof. Behavior changes needed to enforce these rules need causal precode tests and preserved earlier failures in their own source task.

Store consumers continue to accept the existing Store surface. The storage owner defines only the filesystem and synchronous database operations actually needed below it. Preserve native transaction, fd-relative custody, inode/device, journaling, bounded read and current-use semantics; a simplified string-reader facade is insufficient for protected sources. Process/network owners retain bounded command/transport/teardown protocols rather than exposing arbitrary host execution to model arguments. Configuration and secrets arrive as explicit values; executable roots alone read argv/env and select production adapters.

## Trusted composition and release

Mockability is a host construction capability. Live qualification factories privately select actual adapters and bind the accepted implementation/source closure. Synthetic test composition must remain visibly synthetic and cannot authenticate its own sensor, signing authority or live label. Keep current public live-caller override refusals. If replacing host sensors needs a new qualification capability/manifest, L01/L08 must specify it before implementation; this decision adds no permissive format. Interface shape itself is not authenticity.

DI03–DI12 and DI06a may now receive finite disjoint claims from root. The accepted plan's exact interface-release protocol applies: each author commits precode interface semantics and test doubles; dependent authors may consume that frozen contract while implementation proceeds, but component/whole-system acceptance requires the actual exact joined implementation. No mutual acceptance wait is permitted. Root owns out-of-scope constructor/call-site wiring and existing-test fixture changes by exact separate claim; authors report these needs rather than editing siblings. Every source result gets fresh independent review and unchanged behavioral regression evidence. The active b2/b3/control sources remain exclusively owned until released.
