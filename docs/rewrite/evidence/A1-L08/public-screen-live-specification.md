Durable claims prevent repeat execution or fresh state from laundering an attempted case/grant. For process-based acquisition, use an existing protected host boundary for secrets, never CLI arguments, public boot descriptors, candidate state or evidence dumps. A live request uses the ordinary production transport; offline verification uses a separately labelled synthetic entrypoint. Neither may silently fall back into the other.
6. Join actual active work before observation/shutdown. A stale `waiting` row or a start checkpoint's message sequence does not prove completion. Retain source manifests, original grants, process transitions, raw request/response artifacts, tool receipts, checkpoints, assessments, unknown charges and failures within the frozen evidence bound. 7. Public-screen results establish only their observed case behavior. They are not held-out competence, calibrated parity, developmental growth, release admission or H1. Authentication establishes origin and integrity, not evaluator competence. Preserve explicit ineligibility for automatic admission; independently qualified review and later held-out experiments remain separate.
