All exported results are detached **unsigned** facts, never attestations. No observer key, signer callback, live Store or checker execution callback occurs in these helpers. - `experience`: source `{configurationDigest,assignmentPacket,assignment,episode:JournalRef,ingested:JournalRef,creation:DevelopmentEventPosition}`, checks empty, `episodeId`.

- `opportunity`: source `{configurationDigest,assignmentPacket,assignment:DevelopmentAssignmentProof,related:DevelopmentAssignmentProof[]}`, `check:Signed<DevelopmentSourceCheck>`, `output,feedback,acquisition,behavior,disclosure,matching`.

`SourceAdmissionResult<T>` discriminates `{status:'derived',proof:T}` and `{status:'failed'|'unavailable',code:string}`.
