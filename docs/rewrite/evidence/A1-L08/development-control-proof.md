## Implemented source boundary

The frozen three exports are implemented without an execution callback, Store, signer, network request, checker execution or recorder admission. Inputs are detached through descriptor-only plain records and dense arrays; proxies/accessors are refused before reflection, the native checker key is copied, and the two captured-reader functions are pinned and called with copied references and no receiver. Current-use checks remain live and run again after derivation. The accepted integration context remains a prerequisite; this collector does not authenticate an acquisition plan on behalf of a recorder.

The collector recomputes each assignment through b1 and each ablation opportunity from its task and exact declared learning/interference/feedback assignments. All twelve opportunities and the complete ordered role schedule are mandatory. Full original/local captured journal prefixes are checked with equal-cut source projections, then narrow assignment projections provide bounded proof objects. This avoids serializing a whole-role assignment projection into a single proof slot. Bounds remain fixed; no source history is truncated. Aggregate physical transition entries contain exact event positions and full transition digests; redundant request/status columns were removed after the full aggregate exceeded q. Execution request IDs remain explicit, and every actual retained transition/state/lineage is still checked before issuing the unsigned result.

Initial and final mode-seal values, the revision-1 creation and sole mode-sealed event, intermediate standing-goal/consolidation/extension history, actual original root and role allocation, immutable grant/window and matched resources/model/context all participate. Every local physical request must map to original reserved and dispatched states, an unbroken before-digest chain, and identical current physical/bridge inventory. Unknown settlement remains unavailable. Effective ablation provider payloads are read from their exact hashed retained bytes using their ordinary JSON transport encoding; the no-memory context/tools and no-standing-goals agenda/tools are checked independently of the supplied mode name.

Scripts validate the scripted kind before using the source-owned static algorithm exports. They recompute the stable effect ID, inspect the actual effect and result-observation versions, read original operational input/receipt bytes, check the algorithm source digest and exact output, and require the actual original settlement/receipt/usage correspondence. Each task and feedback emission is separately bound. Arbitrary/model requests are denied for scripts. Replay and reopened-application resume cause no new physical request. Existing receipts are never rewritten to a later source digest.

`acquisition`, `behavior` and `validity` are separate. A complete acquisition with a fixture-authenticated failing judgment stays `completed`/`fail`; fixture-authenticated passing ablation judgments stay passing. Independent control validity is always `unavailable`. The generic serializer checks exact top/source/interval/execution fields and the actual byte bound; serialization alone conveys no source truth or admission authority.
