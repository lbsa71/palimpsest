Source `ee8b86f`, 2026-10-11. Requirements RW14, RW16 and RW17; A1-L09 integration.

The former ID-only list required every alternative to retain the incumbent's price descriptor and request limits, and ordinary supervisor startup did not populate alternative IDs. The ordinary path now accepts `allowedModelProfiles` in private host configuration, validates it during installation and supervisor startup, passes it into the frozen service, and exposes it through `model_profiles`. Each profile includes provider, pinned model, reasoning/effort, context/output/request/time limits and explicit input/output prices. The current accepted model remains available without an additional grant.

Candidate settings may select an exact granted provider/model/effort/price combination and reduce request bounds. They cannot fabricate cheaper pricing, enlarge a bound, or change host permissions, network grants, eligibility or operating allowances. The selected descriptor is frozen into the candidate's model/configuration identity. A grant is permission, not proof of competence, entitlement or current vendor pricing. Independent evaluation and release remain required; no provider is silently substituted.
