Implementation is a thin adapter over `ReleaseController`, `AuthorityStore` and `ServiceProcess`. It adds no second release journal and no parallel release mutation path. The host controls use a private Unix socket and exact command fields. Admission reads only `sha256:` content-addressed host blobs. Host policy loading verifies the complete public descriptor, exact evaluator key set, file permissions and key-content digests. Bootstrap authenticates before initializing authority and permits only exact-grant retry of an interrupted initial journal write. Accepted startup is offline and selects a fresh authority generation.

Before the first authority write, `state/bootstrap-intent.json` durably binds the exact externally signed proof and policy identity. An interrupted initialization rejects a different valid proof for that same grant; it must resume the original accepted intent. This hash record contains no private key and is not consulted during accepted recovery.
