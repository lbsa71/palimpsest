# Architecture entry point

The active design is the [Aeon rewrite architecture](rewrite/architecture.md), supported by the [agent-shell decision](rewrite/agent-shell-decision.md), [requirements](../REQUIREMENTS.md), [plan](../PLAN.md), and [ADR 0031](adr/0031-aeon-rewrite-and-prompt-sovereignty.md).

The user authorized a full rewrite on 2026-10-11. The previous installation is retired; no old interface, storage layout, dependency or release protocol is a compatibility requirement. Proposed rewrite packages and commands do not exist merely because they are described in the design.

The [previous architecture](history/pre-aeon-2026-10-11/docs/architecture.md) and other pre-rewrite component documents remain historical evidence. Use the [reuse ledger](rewrite/reuse-ledger.md) to justify retaining a mechanism on its merits.
